# CashFlow Manager

CashFlow Manager is an offline-first Flutter app for Android and iOS that helps users manage personal expenses, wallets, budgets, cashflow forecasts, saving goals, and monthly reports in Vietnamese.

## Features

- Local-first dashboard with current balance, monthly income, monthly expense, net cashflow, chart, recent transactions, and budget alerts.
- Transaction management for income, expense, wallet/category/date/note, recurring flag, and validation.
- Wallet/account overview for cash, bank, e-wallet, credit-card-ready model, and transfers.
- Monthly budget create/edit/delete flow with warning threshold logic.
- Reports with income/expense chart, category pie, top spending, CSV preview, and PDF sharing.
- Cashflow forecast from future recurring occurrences with upcoming bill reminders.
- Saving goals with create/edit/delete flow and monthly saving suggestion logic.
- Backup/restore JSON flow through native file picker/share integrations.
- Privacy lock service with PIN hashing and biometric support path.
- Android and iOS project structure generated by Flutter.

## Tech Stack

- Flutter 3.44 / Dart 3.12
- Riverpod for state management
- SQLite via `sqlite3` + `sqlite3_flutter_libs`
- `fl_chart` for charts
- `local_auth` + `flutter_secure_storage` for local lock
- `csv`, `pdf`, `printing`, `share_plus`, `file_picker` for export and backup flows
- GitHub Actions CI for analyze, tests, Android debug builds

## Quick Start

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## Android Build

```bash
flutter build apk --debug
flutter build appbundle --debug
flutter build apk --release
flutter build appbundle --release
```

Release signing requires standard Android keystore setup outside this repo. Do not commit keystores or passwords.

## iOS Build

The iOS structure exists under `ios/`. Build/archive requires macOS with Xcode:

```bash
flutter pub get
flutter build ios --release
```

Then archive through Xcode or Fastlane on a macOS runner.

## Test

```bash
flutter test
```

Current coverage focus:

- Money parsing and VND formatting edge cases
- Wallet balance logic across income, expense, transfer
- Budget warning logic
- Saving goal monthly suggestion
- Empty export behavior and PDF payload generation
- Privacy lock, dashboard, transaction, wallet transfer, budget, goal, report, export, and backup widget flows

## Project Structure

```text
lib/
  app/                 # Theme and app-level setup
  core/                # Finance models, money math, export, privacy lock
  data/                # Local SQLite store
  features/home/       # Riverpod controller and main mobile UI
test/                  # Unit and widget tests
docs/                  # Product, technical, database, UI, test, release docs
.github/workflows/     # CI
```

## Privacy Notes

Financial data is local-first. PINs are salted and hashed before storing in secure storage. `.env*`, `.claude/`, `.omc/`, `plans/`, and `CLAUDE.md` are ignored by git.

## Known Limitations

- Supabase/Firebase sync is intentionally out of MVP scope.
- Receipt image/OCR is deferred.
- iOS release archive cannot be verified on Windows; use macOS/Xcode.
- Current UI is functional and ready for deeper polish/animation loop.
