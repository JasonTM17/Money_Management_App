# Project Roadmap / Lộ trình dự án / プロジェクトロードマップ

## English

### v1.0 (Current — Q2 2026)
- [x] Offline-first finance manager with SQLite + Riverpod
- [x] Income, expense, transfer transactions
- [x] Wallets (cash, bank, eWallet, credit card)
- [x] Budgets with monthly tracking
- [x] Saving goals with progress
- [x] Export (CSV, PDF)
- [x] Backup/restore with passphrase encryption
- [x] Privacy lock (biometric + PIN)
- [x] Fastify API with JWT (EdDSA)
- [x] Docker Compose stack (PostgreSQL, API, nginx frontend, n8n)
- [x] CI/CD with GitHub Actions
- [x] 3-language UI (Vietnamese, English, Japanese)
- [x] ADR documentation

### v1.1 (Planned — Q3 2026)
- [ ] Multi-currency support (VND, USD, JPY)
- [ ] Recurring transaction automation
- [ ] Data sync via API
- [ ] Offline queue with conflict resolution

### v1.2 (Planned — Q4 2026)
- [ ] Multi-device sync
- [ ] Web dashboard (PWA)
- [ ] Push notifications for budget alerts
- [ ] AI spending analysis (n8n + GPT)
