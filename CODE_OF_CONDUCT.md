# Code of Conduct

## Expected Behavior

- Be respectful and constructive.
- Keep discussions focused on improving CashFlow Manager.
- Report security issues privately through the security policy.
- Avoid sharing real financial data, secrets, tokens, or credentials in issues, pull requests, screenshots, or logs.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing private user data or credentials.
- Posting exploit details publicly before maintainers can assess and fix a vulnerability.
- Deliberately disrupting project infrastructure or release workflows.

## Enforcement

Maintainers may edit, hide, or remove comments and contributions that violate this code of conduct. Repeated or severe violations may result in a ban from project participation.
